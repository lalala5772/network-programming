# Network Programming Practice

Java Socket을 활용한 네트워크 프로그래밍 실습 코드 모음. 
클라이언트와 서버 간 TCP 통신을 구현하고, 데이터 스트림을 이용한 데이터 송수신 및 파일 전송 과정 공부

## 프로젝트 개요

- **언어**: Java
- **개발 환경**: Eclipse
- **핵심 기술**: Java Socket, TCP, DataInputStream, DataOutputStream
- **주요 학습 내용**: 클라이언트-서버 통신, 데이터 직렬화 및 송수신, 학생 정보 관리, 파일 전송

## 실습 구성

### 1. Student Management System

`practice1`은 클라이언트와 서버 간 통신을 통해 학생 정보를 관리하는 프로그램


**구현 내용**
- `ServerSocket`과 `Socket`을 이용한 서버 및 클라이언트 연결
- `DataInputStream`과 `DataOutputStream`을 활용한 데이터 송수신
- 메뉴 번호에 따른 클라이언트 요청 처리
- `StudentDTO`를 이용한 학생 데이터 관리
- `StudentDAO`를 이용한 학생 정보 등록 및 조회, 수정, 삭제 로직 구현

### 2. File Transfer Practice

`practice2`는 데이터 스트림을 활용해 서버와 클라이언트 간 파일을 전송하는 실습임.

**주요 기능**
- 서버 측 파일 목록 전송
- 클라이언트에서 전송할 파일명 입력
- 파일 크기 및 파일 데이터 전송
- 수신한 파일을 로컬 경로에 저장

**구현 내용**
- 파일 입출력 스트림과 네트워크 스트림 연계
- `FileInputStream`, `FileOutputStream`을 이용한 파일 읽기 및 저장
- `readFully()`를 활용한 지정된 크기의 데이터 수신
- 파일명, 파일 크기, 파일 내용을 순서대로 교환하는 통신 과정 구현

## 실행 방법

### 개발 환경

- Java 실행 환경
- Eclipse IDE 또는 Java 프로젝트를 실행할 수 있는 개발 환경


## 학습 목표

- TCP 기반 클라이언트-서버 통신 구조 이해
- 소켓 연결과 입출력 스트림의 역할 이해
- 클라이언트 요청에 따른 서버 측 처리 흐름 구현
- 객체를 활용한 데이터 관리와 CRUD 로직 구성
- 파일 입출력과 네트워크 데이터 전송의 연계 방식 이해
- 데이터 송수신 순서와 데이터 크기 관리의 중요성 학습

## 참고 사항

- 서버와 클라이언트는 동일한 포트 번호를 사용하도록 구성되어 있음.
- 일부 파일 전송 코드에는 개발 환경에 종속된 로컬 경로가 포함되어 있으므로, 다른 환경에서 실행할 경우 경로를 수정해야 함.
- 학습 및 실습을 목적으로 작성한 코드임.
